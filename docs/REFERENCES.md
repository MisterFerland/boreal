# Primary references consulted

Consulted 2026-10-29. These references inform engineering; they do not certify this portfolio.

- [GnuCOBOL project](https://gnucobol.sourceforge.io/): current stable release 3.2.
- [GnuCOBOL manual](https://gnucobol.sourceforge.io/doc/gnucobol.html): native compilation, runtime checks, fixed decimal and file status.
- [PostgreSQL numeric types](https://www.postgresql.org/docs/current/datatype-numeric.html): exact bounded NUMERIC storage.
- [PostgreSQL SELECT](https://www.postgresql.org/docs/current/sql-select.html): row locking and SKIP LOCKED worker claims.
- [PostgreSQL supported versions](https://www.postgresql.org/support/versioning/): 17 is supported; 17.11 selected for local testing.
- [FastAPI documentation](https://fastapi.tiangolo.com/): typed transport and dependencies.
- [Vite guide](https://vite.dev/guide/): production build and supported Node runtime.
- [WCAG 2.2](https://www.w3.org/TR/WCAG22/): AA is an engineering target, not a claim of comprehensive conformance.
- [Canadian digital standards](https://www.canada.ca/en/government/system/digital-government/government-canada-digital-standards.html): user-centred, accessible and evidence-based service design.
- [Canadian ICT accessibility transition direction](https://www.canada.ca/en/government/system/digital-government/policies-standards/policy-service-digital-announcements/direction-information-communication-technologies-accessibility-towards-regulatory-implementation.html): institutional obligations and transition planning extend beyond this local browser assessment. The notice references CAN/ASC–EN 301 549 and regulatory dates in 2027/2028. Contract requirements require their own assessment.

Package pins and lockfiles record the registry versions actually installed. Runtime version and verification reports are recorded under artifacts/. No externally hosted assets are needed after installation.
